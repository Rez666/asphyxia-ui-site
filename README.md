# Asphyxia-UI

A dark, neon-lit custom interface for **WoW Forever**: unit frames (Morph, Norm, Eclipse, Dark Matter), action bars, inventory, damage meter, Raid Control and skinned Blizzard windows.

- **Website:** https://asphyxia-ui.com
- **Download:** [Asphyxia-UI.zip (latest validated build)](https://github.com/Rez666/asphyxia-ui-site/releases/download/asphyxia-latest/Asphyxia-UI.zip)
- **Community and support:** the Asphyxia-UI Discord (link on the website)

## Install
1. Close WoW Forever.
2. Back up your `Interface/AddOns` and `WTF` folders.
3. Extract `Asphyxia-UI.zip` and place the `Asphyxia-UI` folder in `Interface/AddOns`, replacing any older copy. Keep `WTF` to preserve your settings.
4. Enable Asphyxia-UI in the addon list and log in.
